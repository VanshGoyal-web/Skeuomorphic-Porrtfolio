# ✦ The Personal Desk — Vansh Goyal

> A personal portfolio designed to look and feel like a beautifully crafted physical desk.

Welcome to my personal portfolio! Instead of following the usual modern portfolio layout, I wanted to create something different — a digital workspace inspired by classic stationery, leather-bound notebooks, brass details, and vintage desk accessories.

The idea is simple: **my portfolio should feel like a personal desk, not just another website.**

## ✨ Features

- **Skeuomorphic Design:** A tactile interface featuring cream paper, green leather textures, brass accents, and raised buttons.
- **Day & Evening Modes:** Switch between two different desk atmospheres.
- **Interactive Python Pattern Generator:** Generate different star patterns, adjust their size, and view the corresponding Python code.
- **GCD & LCM Explorer:** Experiment with numbers, calculate GCD and LCM, and explore prime factorisation and Euclidean algorithm steps.
- **Personal Scratchpad:** Write and save notes locally in your browser.
- **Responsive Layout:** Designed to work across desktop and smaller screens.

## 🚀 Run Locally

You can run this project directly on your computer.

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd vansh-skeuomorphic-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in VS Code and use the **Live Server** extension.
